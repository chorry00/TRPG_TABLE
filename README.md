## 🎲TRPG TABLE とは
AIをGMとしてTRPG(テーブルトークRPG)風に遊ぶ専用UIです。各種のAPIと接続して使います。


## 主な機能
#### API接続
* APIは各社のものが使えます。
* ローカルモデルとの接続は現時点では実装していません。

#### ダイスロール機能
* 行動の成功判定のためにダイスを振る(ダイスロール)機能が内蔵されています。
* ダイスロールはUI側で行なっておりAIのような出目への忖度はありません。いい場面でも無慈悲に失敗します。

#### ゲーム形式
* 2種類の形式から選べます。
  * ゲームブック形式：選択肢から行動を選びます。自由入力も可能です。
  * TRPG形式：自由入力のみで進めます。入力後に必要なダイス判定を決めます。
* ゲームの長さは 長編・中編・短編 から選べます。

#### キャラクター作成
* 簡単な手順でプレイヤーキャラクターを作成できます。
* 名前と簡単な経歴を入力すると、AIが各能力値と所持スキル候補を自動作成します。
* 能力値と所持スキルはダイスロールによる成功判定に修正を加えます。

#### 所持品と同行者
* ゲーム中に入手したアイテムや同行者はキャラクターシートに自動登録されます。
* 所持品と同行者もダイスロールによる成功判定に修正を加えます。

#### ゲームの舞台と目的の設定
* ゲームの舞台と目的を自由に設定できます。これにより定番のファンタジー世界の他にも、現代を舞台にしたミステリー、学園を舞台にした恋愛物、歴史物などお好みの設定で遊べます。
* 考えるのが面倒な時は自動作成もできます。

#### システムプロンプトの入力
* ゲームの雰囲気やナレーションの文体などを指示することが可能です。指示しない場合はデフォルトの設定を使います。
* コメディ/ギャグ色を強めたい、甘々な恋愛物にしたいなどの指示もできます。
* センシティブなシナリオがどこまで通るかはAIモデルの選択とシステムプロンプトの内容に左右されます。なおこの点について作者は一切お答えできません。自己責任でお願いします。

#### スマホ画面での操作
* 画面を左からスワイプするとセッション一覧が開きます。右からスワイプするとキャラクターシートが開きます。閉じる時はメイン画面の領域をタップしてください。
* キャラクターの能力値の上でタップすると説明が表示されます。再びタップすると消えます。


## 遊び方のヒントなど
#### ゲームの展開
シナリオの進行中にところどころでイベントを起こすように設計していますが、面白い展開になるかどうかは使用するAIモデルの賢さに依存します。展開が気に入らない・同じような展開が続いて退屈だ等という場合は自由入力をうまく使ってください。新キャラを登場させたり強制的に場面転換させるのもいいでしょう。「GMへの要望」を使って展開を変えることもできます。
#### エンディング
ゲーム中にあなたが取った行動が good / bad の両面で評価・累積されており、それらの総合評価に基づいてAIがエンディングを決定します。なお good / bad は単純に行為の善悪ではなく、**「ゲーム開始時に決めた目的」** の達成に対して 良い影響か/悪い影響か で評価されます。これによりダークヒーローを演じることも可能です。
実際にどんな評価がされたかは「冒険のメモ」内の「AIの振り返り」から見ることができます。本来はデバッグ用の機能ですが敢えて残してあります。覗いてみると面白いかもしれません。
#### 申し訳
行動選択後にAIから回答拒否(いわゆる申し訳)をされた場合に備え、送信したプロンプトを手動で書き換える機能を持たせていますが、いつもうまく動作するとは限りません。うまくいかない場合は諦めてください。
